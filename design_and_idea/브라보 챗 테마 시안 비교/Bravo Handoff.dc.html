3 · 반응형 전략

컴포넌트를 이원화하지 않는다. 공유 컴포넌트 + 레이아웃 셸만 분기. 버블·위젯·입력바는 그대로 재사용하고, 감싸는 셸만 브레이크포인트로 나눈다.

MOBILE · < 768px
단일 컬럼
마스코트 → 위젯 2×2 → 채팅 → 입력바. 풀스크린.
DESKTOP · ≥ 768px
사이드바 + 본문
좌: 마스코트·위젯 패널 / 우: 채팅 컬럼(중앙 정렬, max-w).

5 · 데이터 & 상호작용 모델

type Message =
  | { id: string; who: 'user';     text: string }
  | { id: string; who: 'bot';      text: string }
  | { id: string; who: 'schedule'; items: string[] }
  | { id: string; who: 'options';  options: string[] };

type Widget = { id: string; icon: string; label: string;
                meta?: string; prompt: string };
흐름 · 위젯 클릭 → prompt를 유저 메시지로 주입 → 봇 pending(타이핑) → 응답 append → 스크롤 하단 고정. 입력바는 텍스트 + 음성(누르고 말하기) 두 진입.

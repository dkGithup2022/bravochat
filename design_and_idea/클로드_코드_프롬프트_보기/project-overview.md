# 프로젝트 개요 — Claude Code CLI 소스 코드

## 이게 뭔가요?

Anthropic의 **Claude Code**(터미널에서 쓰는 AI 코딩 도우미)의 소스 코드입니다.
TypeScript로 작성되어 있고, 특이하게도 터미널 화면을 **React**로 그립니다
(웹 브라우저 대신 터미널에 React 컴포넌트를 렌더링해 주는 "Ink"라는 라이브러리를 자체 수정해서 내장하고 있습니다).

- 규모: TypeScript 파일 약 1,900개, 약 47만 줄
- 실행 환경: Bun (Node.js 계열의 빠른 자바스크립트 런타임)
- 참고: `main.tsx`(약 80만 바이트)는 사람이 쓴 코드가 아니라 빌드 과정에서 합쳐진 번들 파일이라, 읽는 대상에서 제외했습니다.

## 프로그램이 시작되는 순서

1. **`entrypoints/cli.tsx`** — 진짜 시작점. 빠른 실행을 위해 필요한 모듈만 그때그때 불러옵니다.
2. **`entrypoints/init.ts`** — 프로세스 초기화 (설정 로딩, 로그인 정보, 프록시/인증서, 사용량 측정 도구 준비).
3. **`setup.ts`** — 프로젝트별 준비 (작업 폴더와 git 저장소 찾기, 세션 메모리 초기화 등).
4. 이후 채팅 화면(`screens/REPL.tsx`)이 뜨고 대화가 시작됩니다.
   - REPL은 "입력받고 → 실행하고 → 결과 보여주기"를 반복하는 대화형 화면을 뜻하는 용어입니다.

## 핵심 동작 원리 — AI 에이전트 루프

사용자의 메시지 하나가 처리되는 흐름은 3개 층으로 나뉩니다:

```
사용자 메시지
  → QueryEngine.ts   (대화 하나의 전체 수명과 상태를 관리)
  → query.ts         (실제 반복 루프: AI 모델 호출 → 응답 스트리밍)
  → Tool.ts          (AI가 "파일 읽어줘" 같은 도구 사용을 요청하면 실행)
  → 도구 실행 결과를 다시 AI에게 전달 → 답이 끝날 때까지 반복
```

- **`QueryEngine.ts`** — 대화 하나를 책임지는 클래스. 메시지 내역, 읽은 파일 상태, 토큰 사용량, 중단 처리 등을 들고 있습니다.
- **`query.ts`** — Anthropic API를 호출하는 실제 루프. 대화가 길어지면 자동으로 요약해서 압축하고(auto-compaction), API 오류 시 재시도나 대체 모델 전환도 여기서 처리합니다.
- **`Tool.ts`** — 도구의 공통 규격. 각 도구는 입력 형식 검증(zod 라이브러리)과 권한 확인(사용자 허락이 필요한지)을 거친 뒤 실행됩니다.
- **`Task.ts`** — 백그라운드 작업(서브 에이전트, 원격 실행 등)의 종류와 상태를 정의합니다.

## 주요 기술 스택

| 영역 | 사용 기술 |
|------|-----------|
| 터미널 UI | React + 자체 내장한 Ink 렌더러 (`ink/`), 레이아웃 계산은 flexbox 엔진을 직접 TypeScript로 포팅 (`native-ts/yoga-layout`) |
| AI 호출 | `@anthropic-ai/sdk` (스트리밍 응답) |
| 외부 도구 연동 | `@modelcontextprotocol/sdk` — MCP(외부 프로그램을 AI 도구로 연결해 주는 표준 프로토콜) |
| 입력 검증 | zod (v4) |
| 빌드 | Bun — 내부용/외부 배포용 빌드를 기능 플래그로 나눠서 안 쓰는 코드를 제거 |
| 모니터링 | OpenTelemetry (사용량·오류 지표 수집) |

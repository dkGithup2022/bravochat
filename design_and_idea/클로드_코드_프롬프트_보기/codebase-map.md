# 폴더 지도 — 어디에 뭐가 있나

전체 구조를 얕게 훑은 결과입니다. 큰 폴더부터 순서대로 정리했습니다.
(전체 흐름은 [project-overview.md](project-overview.md) 참고)

## 큰 폴더 5개 (코드의 대부분)

### `utils/` — 잡다한 공용 코드 모음 (564개 파일, 약 18만 줄)
가장 큰 폴더. 파일 이름으로 보면 이런 분류가 있습니다:
- 인증/보안: 로그인, AWS 연동, 인증서, 민감정보 저장
- git/GitHub: 저장소 감지, diff, PR 상태, 워크트리(한 저장소를 여러 폴더에 동시에 체크아웃하는 git 기능)
- 셸/프로세스: 명령어 실행, 샌드박스(격리 실행)
- 세션 저장/복원, 파일 검색(ripgrep), 토큰 계산, 원격 측정(telemetry) 등

### `components/` — 터미널에 그려지는 UI 조각들 (389개 파일)
채팅 메시지 표시, 입력창, 각종 선택 대화상자(모델 선택, 테마 선택, 권한 허용 등),
온보딩(첫 사용 안내) 화면, 상태 표시줄 같은 화면 요소가 전부 여기 있습니다.

### `commands/` — 슬래시 명령어 (189개 파일)
사용자가 `/`로 시작해 입력하는 명령어들. 대략적인 분류:
- 대화 관리: `/clear`, `/compact`(대화 압축), `/resume`, `/export`
- git 작업: `/commit`, `/review`, `/pr_comments`
- 설정: `/config`, `/model`, `/theme`, `/doctor`(문제 진단)
- 확장 기능: `/mcp`, `/plugin`, `/skills`, `/hooks`, `/agents`
- 로그인·요금: `/login`, `/cost`, `/usage`

### `tools/` — AI가 쓸 수 있는 내장 도구 (184개 파일, 약 40종)
- 파일: 읽기, 쓰기, 수정, 검색(Glob/Grep), 노트북 편집
- 실행: Bash, PowerShell
- 웹: 페이지 가져오기, 검색
- 에이전트: 서브 에이전트 생성, 백그라운드 작업 관리, 팀 협업
- 기타: 계획 모드 진입/종료, MCP 연동, 스킬 실행, 사용자에게 질문하기

### `services/` — 백그라운드 기능 서비스 (130개 파일)
API 통신, OAuth 로그인, MCP 연결 관리, 대화 자동 요약(compact),
메모리 동기화, 음성 입력(STT), 사용 통계, 알림 등.

## 화면과 입력

| 폴더 | 설명 |
|------|------|
| `screens/` | 최상위 화면 3개 — 메인 채팅(`REPL.tsx`), 대화 이어하기, 진단 화면 |
| `ink/` | 터미널용 React 렌더러 (Ink 라이브러리를 자체 수정해 내장한 것) |
| `hooks/` | UI용 React 훅 (입력 버퍼, 단축키, 클립보드 등) |
| `keybindings/` | 키보드 단축키 커스터마이징 시스템 |
| `vim/` | 입력창에서 쓸 수 있는 Vim 편집 모드 (이동, 삭제 등 명령 구현) |
| `buddy/` | 터미널에 표시되는 애니메이션 마스코트(펫) 기능 |

## 시작과 연결

| 폴더 | 설명 |
|------|------|
| `entrypoints/` | 프로그램 시작점들 — 일반 CLI, MCP 서버 모드, SDK(코드에서 직접 호출하는) 모드 |
| `cli/` | 비대화형 실행(print 모드), 입출력 방식 처리 |
| `bootstrap/` | 전역 상태 저장소 (현재 폴더, 세션 ID, 비용 카운터 등) |
| `bridge/` | 로컬 터미널 세션을 Anthropic 원격 서비스(모바일 앱 등)와 연결 |
| `remote/` | 클라우드에서 돌아가는 원격 세션 관리 (WebSocket 통신) |
| `server/` | 로컬 서버 모드 — 외부 프로그램이 이 세션에 접속할 수 있게 함 |
| `upstreamproxy/` | 컨테이너 환경에서 네트워크 트래픽을 회사 프록시로 중계 |

## 기능별 폴더

| 폴더 | 설명 |
|------|------|
| `skills/` | 스킬(패키지된 작업 지침서) 검색·로딩 |
| `tasks/` | 백그라운드 작업 실행 방식들 (로컬 에이전트, 원격 에이전트, 셸 작업 등) |
| `memdir/` | 지속 메모리 저장소 — 세션이 끝나도 기억을 파일로 남기는 기능 |
| `migrations/` | 버전 업그레이드 시 설정 파일을 자동 변환하는 코드 |
| `native-ts/` | 원래 Rust로 만들었던 모듈들의 TypeScript 포팅 (문법 강조 diff, 퍼지 파일 검색, flexbox 레이아웃) — 네이티브 의존성 없이 돌아가게 하기 위함 |
| `voice/` | 음성 모드 켜기/끄기 (실제 음성 인식 로직은 `services/`에 있음) |
| `constants/`, `types/`, `schemas/`, `state/`, `context/` | 상수, 타입 정의, 데이터 형식, 상태 관리 등 지원 코드 |

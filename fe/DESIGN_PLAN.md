# Design Implementation Plan: RecordsPage (/records)

> 이전 계획(SchedulesPage, Variant C)은 2026-07-29 구현 완료되어 본 문서를 기록 화면 계획으로 교체.

## Summary
- **Scope:** 페이지 (보호 라우트)
- **Target:** `src/app/records/page.tsx` + `src/components/record/*` + `src/features/record/*`
- **Winner variant:** C — 타임라인 (실전 보완판)
- **데이터 모델:** `{ id, 일자(date), 요약(summary), 타입(type) }` — 과거 대화에서 자동 요약된 이력, **최신순** 표시
- **조작 범위:** 읽기 + 삭제만 (수정/등록 없음 — 자동 생성 데이터)

## ⚠️ 선행: BE 계약 미확정
기록 API 는 아직 BE 에 없음. FE 는 아래 가정 계약으로 목 먼저 구현하고, BE 확정 시 교체:
- `GET /records?from&to&size` (또는 커서) → `{ records: [{ recordId, date, summary, recordType }] }` 최신순
- `DELETE /records/{recordId}` → 204, 404(타 유저/없음)
- **타입 체계 미정** — FE 는 문자열로 받고 라벨 매핑만 교체 가능하게 (`분류A/B/C` 자리표시자)

### 타임라인 (flex-1 overflow-y-auto, `px-6 pt-4`)
- 컨테이너: `border-l-[1.5px] border-line pl-5` (좌측 세로 라인)
- 날짜 그룹 헤더: 라인 위 도트 `-left-[26.5px] h-[11px] w-[11px] rounded-full border-[2.5px] border-ink bg-white` + `오늘/어제/M월 D일`(bold 14px ink) + `7.29 (수)`(mono 11px faint). **최신 날짜가 위.**
- 기록 항목 (`gap-[12px]`, group):
  - 요약: `text-[14px] leading-relaxed text-ink`, 접힘 시 `line-clamp-2`, **탭/Enter 로 펼침** (`aria-expanded`)
  - 메타 줄: 타입 라벨 `font-mono text-[10px] text-faint` + 삭제 Trash2(13) — `hidden group-hover:block`, **펼침 시 항상 노출** (터치 대응)
  - 삭제 전 `confirm` (요약 40자 미리보기 포함)
- 말미: `대화에서 의미 있는 이력이 자동으로 기록됩니다` (mono 11px faint 중앙)

### 상태
- **Empty:** `아직 기록이 없어요` + `대화하다 보면 의미 있는 이력이 자동으로 쌓여요`
- **Loading/Error:** 일정 화면 문구 톤 재사용 (`기록을 불러오는 중…` / `다시 시도`)
- 삭제 404 → 토스트 + 목록 재조회 (일정과 동일 패턴)
